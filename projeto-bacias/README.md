# Projeto de Análise de Bacias Hidrográficas

## Área de estudo
Gestão de recursos hídricos e análise ambiental de bacias hidrográficas.

## Objetivo
Desenvolver uma proposta de análise integrada de variáveis ambientais e territoriais para compreender as relações entre uso e ocupação do solo, conectividade hidrológica e dinâmica das bacias hidrográficas.

## Competências demonstradas
- Pesquisa e revisão bibliográfica
- Análise ambiental
- Gestão de recursos hídricos
- Interpretação de dados ambientais
- Planejamento de pesquisa
- Integração de variáveis territoriais e ambientais

## Natureza do trabalho
Proposta acadêmica de pesquisa.
